# Module 1 — Sponsor Management

The implementation uses the report's English model names: Member, Organizer, Sponsor and Contract. Pages and messages are also in English.

The project follows the [JSP/JDBC implementation tutorial](https://softwaredesign.home.blog/tutorials/he-thong-quan-li-dang-ki-tin-chi-va-diem-sinh-vien/cai-dat/): model classes, DAO classes extending a shared JDBC DAO, display JSP pages, and `do-*.jsp` pages that process forms and call DAO methods.

See the [project README](../README.md) for the directory structure, Supabase configuration, run commands, tests and WAR deployment.
